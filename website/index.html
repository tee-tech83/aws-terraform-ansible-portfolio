Who I Am

I am a Cloud & DevOps Engineer with hands-on experience architecting, automating, deploying and troubleshooting AWS infrastructure and containerized application environments.

My technical background includes Infrastructure as Code, highly available AWS architectures, CI/CD automation, Docker, Amazon ECS, Kubernetes, Amazon EKS, Linux, networking, IAM and cloud observability.

I build repeatable cloud environments using Terraform and Ansible and integrate GitHub Actions and Jenkins with AWS deployment workflows.

What I Build

I have built multi-tier AWS environments with public and private subnets, EC2, Amazon RDS, S3, Security Groups, NAT Gateways and automated infrastructure provisioning.

I have implemented highly available environments using Application Load Balancers, Launch Templates, Auto Scaling Groups and multiple Availability Zones.

My container and deployment work includes Docker, Amazon ECR, Amazon ECS, Amazon EKS, Kubernetes, Helm, Jenkins and GitHub Actions.
